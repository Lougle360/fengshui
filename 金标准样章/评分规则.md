# 金标准样章 · 评分规则

用途：Skill 每改一版，就用新版重跑这几页和这 15 个片段，再和老师定稿对照打分，判断这一版是变好了还是变差了。

**评分脚本暂不编写。**等老师定稿交回后，按本规则写 `tools/score_gold_sample.py`，读取 `tools/gold_items.json` 和老师定稿。在那之前，可以按本规则人工打分。

---

## 一、专项片段：逐项判定通过或不通过

每个片段只检查与它相关的几项。所有相关项都通过，这个片段才算通过。

| 检查项 | 怎样算通过 |
|---|---|
| 错字已改 | 老师定稿里改正的字，新稿也改了；新稿不再把错字原样写进白话 |
| 术语正确 | 老师定稿中的术语写法和解释，新稿意思一致（措辞可以不同） |
| 无反向意思 | 新稿没有把吉说成凶、把否定说成肯定，或把主语、宾语弄反 |
| “不详”用得对 | 只在老师允许写“不详”的地方出现“不详”“不明”一类说法；老师给出了解释的地方，新稿不得再写“不详” |
| 无流程用语 | 不出现 OCR、识别、释读、模型、乱码、校验等内部用语 |
| 版心已处理 | 版心、页码、刻工名、馆藏印记的处理方式与老师定稿一致 |
| 跨页已接 | 跨页断开的句子接成一句，不再标“不完整” |
| 经注分明 | 读者能分清哪句是经、哪句是注，注文跟在它解释的经文后面 |

各片段对应的检查项：

| 片段 | 必查项 |
|---|---|
| F01、F02、F03 | 错字已改；“不详”用得对；F03 另查术语正确（乾误作干） |
| F04 | 术语正确（乾误作干） |
| F05 | 术语正确；“不详”用得对 |
| F06、F07 | 术语正确；无反向意思 |
| F08 | 版心已处理 |
| F09 | 跨页已接；“不详”用得对 |
| F10 | 经注分明；无反向意思 |
| F11、F12、F13 | 无反向意思；“不详”用得对 |
| F14 | 无流程用语；“不详”用得对 |
| F15 | “不详”用得对（这里应当标明缺文）；不添加原文没有的议论 |

**合格线（待老师定稿后确认）**：15 个片段中至少 13 个通过，并且以下五个必须全部通过：F05（元女）、F09（跨页残句）、F11（过度确定）、F14（流程用语）、F15（真残损）。

## 二、连续正文：统计指标

下表右栏是当前 AI 稿（`V4/002-入地眼全书`，第 83～85 页，现稿约 3000 字）的实测基线，由 `tools/baseline_metrics.py` 统计。

| 指标 | 算法 | 当前基线 | 目标 |
|---|---|---|---|
| “不详”密度 | “具体所指不详”“含义不详”“语义不明”等说法的次数，换算成每万字 | 24 处，约 80 次/万字 | 不超过老师定稿中的次数 |
| 元叙述 | “文中提到”“原文提到”“这一短语”的次数 | 25 次 | 0，除非老师定稿保留 |
| 流程用语 | OCR、识别、释读、模型、乱码、“原文中”等的次数 | 1 次 | 0 |
| 版心残留 | 书名卷次、刻工名混入正文的次数 | 3 次 | 0 |
| 乾误作干 | 原文“乾”在新稿中写成“干”的段块数 | 6 块 | 0 |
| 老师标出问题的修复率 | 老师改动过的段块中，新稿与老师定稿意思一致的比例 | 待定稿后计算 | ≥ 90% |
| 新增错误 | 老师写“同现稿”的段块，新稿反而改错的数量 | 待定稿后计算 | 0 |

说明：

- “修复率”和“新增错误”要逐块比较“意思是否一致”，暂时由人判断。写脚本时可以先用关键词核对，比如老师定稿中改出的关键字和术语是否都出现在新稿里，再人工复核不一致的段块。
- 统计指标只说明方向。最终是否合格，以专项片段的通过情况和修复率为准。

## 三、每次评分要记录的内容

每次打分记一行，放在 `金标准样章/评分记录.md`（第一次评分时创建），内容包括：

- 日期、Skill 版本；
- 片段通过数（例如 11/15），以及没通过的片段编号；
- 连续正文的上述指标；
- 与上一次相比，哪些项变好、哪些项变差。
