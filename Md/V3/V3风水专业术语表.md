# V3 风水专业术语表

本表用于锁定术语写法和释读边界。术语在白话文中保留原词，可以在首次出现时增加括号解释，不得用解释词永久替代原术语。不同流派含义不一致时，应注明流派，不强行统一。

| 术语 | 通俗解释 | 释读边界 |
|---|---|---|
| 阴阳 | 描述事物相反相成、消长转化的两类属性 | 不简化成“正负” |
| 五行 | 木、火、土、金、水五种分类及其关系体系 | 不解释成五种物质 |
| 生克制化 | 五行之间相生、相克以及约束、转化关系 | 保留具体生克链条 |
| 河图 | 传统术数中的数理图式之一 | 不与洛书混称 |
| 洛书 | 传统术数中的九宫数理图式 | 不与河图混称 |
| 八卦 | 乾、坤、震、巽、坎、离、艮、兑八种卦象 | 卦名及次序不得改写 |
| 先天 | 术数中表示先天卦序或本体关系的概念 | 应按上下文注明所指 |
| 后天 | 术数中表示后天卦序或运行关系的概念 | 应按上下文注明所指 |
| 天干 | 甲乙丙丁戊己庚辛壬癸 | 字序不得改变 |
| 地支 | 子丑寅卯辰巳午未申酉戌亥 | 字序不得改变 |
| 干支 | 天干和地支组合形成的纪时、纪序系统 | 不泛化成“日期” |
| 峦头 | 观察山川形势、空间形态的风水方法 | 不等同于一般地形学 |
| 理气 | 运用卦、数、方位、时间等关系判断吉凶的方法 | 保留具体流派语境 |
| 龙 | 风水中山脉、地势及气脉的来势和行度 | 不替换成动物或单纯山脉 |
| 来龙 | 龙脉从远处延伸而来的走势 | 需与入首区分 |
| 入首 | 龙脉进入结穴区域前的关键一段 | 不泛化成入口 |
| 过峡 | 龙脉行进中收束、跌断后再起的部位 | 保留形势判断语境 |
| 穴 | 风水中认为气脉聚结、适宜安葬或营建的位置 | 不简单替换成地点 |
| 结穴 | 山水形势收束并形成穴位的过程或结果 | 不等同于选址 |
| 砂 | 穴场周围起护卫、朝应作用的山丘或地形 | 不解释为沙土 |
| 水 | 风水语境中的河流、水系及其来去形态 | 保留来水、去水等关系 |
| 向 | 建筑或穴位所朝的方位 | 与坐山配合说明 |
| 坐山 | 建筑或穴位背靠的一方 | 不与朝向混淆 |
| 明堂 | 穴前相对开阔、汇聚的空间 | 不等同于建筑大厅 |
| 水口 | 水流出入一地或局势收束的位置 | 应区分来水口、去水口 |
| 案山 | 穴前较近、形如案几的山体 | 与朝山区分 |
| 朝山 | 穴前较远、形成朝拱关系的山体 | 与案山区分 |
| 青龙 | 穴场或建筑左侧的形势称谓 | 不直接等同真实龙形 |
| 白虎 | 穴场或建筑右侧的形势称谓 | 不直接等同真实虎形 |
| 朱雀 | 穴前方的形势称谓 | 应结合明堂、水势解释 |
| 玄武 | 穴后方的靠山形势称谓 | 不只解释为神兽 |
| 生气 | 风水典籍中具有生发、凝聚意义的气 | 不改写成空气或生命力 |
| 旺气 | 在特定时间、方位或格局中处于旺盛状态的气 | 必须保留时空条件 |
| 煞气 | 被认为具有冲射、损害或不利作用的气势 | 不一律解释成邪气 |
| 三合 | 以地支三合等关系构成的一类风水体系或方法 | 应保留具体派别语境 |
| 三元 | 以三元、九运等时序结构为核心的一类体系 | 不与三合混用 |
| 玄空 | 结合时间、空间和星数推演的一类风水体系 | 不泛化成神秘空间 |
| 挨星 | 玄空等体系中按规则排布、推移星数的方法 | 星名、宫位不得改动 |
| 九运 | 三元体系中划分的九个运期 | 运序、年代不得改动 |
| 罗盘 | 风水测向和排布方位层次的专用工具 | 不能仅称指南针 |
| 二十四山 | 将周天划分为二十四个方位的体系 | 山名及次序不得改动 |
| 七十二龙 | 对龙向或分金作更细划分的术数体系 | 不删减具体干支标记 |
| 分金 | 罗盘中进一步细分坐向度数的方法 | 度数和干支必须保持 |
| 纳甲 | 将天干地支等配置到卦爻的术数方法 | 不作字面“接纳甲木”解释 |
| 穿山 | 罗盘及风水体系中的一种龙向分层或推断方法 | 须按原书体系解释 |
| 透地 | 罗盘及风水体系中的一种分金或气脉推断方法 | 须按原书体系解释 |
| 乾 | 八卦之一，卦象及五行、方位依原文语境确定 | 不只译为天空 |
| 坤 | 八卦之一，卦象及五行、方位依原文语境确定 | 不只译为大地 |
| 震 | 八卦之一 | 卦名保留 |
| 巽 | 八卦之一 | 卦名保留 |
| 坎 | 八卦之一 | 卦名保留 |

## 自动处理规则

1. 原文出现本表术语时，白话文必须保留该术语。
2. 若为了句子通顺需要补充解释，应使用“术语（解释）”形式。
3. 若同一词在不同流派有不同定义，应写明“本书此处所说的……”，不得扩展成全行业统一定义。
4. 对本表未收录但模型识别出的术语，写入中间结果；经过全书一致性检查后再补充到本表。
